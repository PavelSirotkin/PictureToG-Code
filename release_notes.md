# PictureToG-Code V 1.1

Крупное обновление: добавлен режим генерации по средней линии, 3D-просмотр траектории и веб-версия приложения.

## ✨ Новые возможности

### 🖋 Режим «Средняя линия» (скелетизация)

Новый способ генерации G-кода — фреза идёт **по центру штриха**, а не обводит фигуру по контуру.

- Утончение изображения алгоритмом Чжана-Суэня (Zhang-Suen) до скелета толщиной 1 пиксель
- Автоматическая чистка скелета (схлопывание диагональных «лесенок»)
- Отсев коротких заусенцев, создающих ложные точки ветвления
- Сшивка сегментов в длинные непрерывные линии по принципу прямого продолжения
- Компенсация радиуса фрезы не применяется — инструмент проходит точно по линии
- Идеально для гравировки рукописного и каллиграфического текста, штриховых рисунков

Включается флажком «Средняя линия» в режиме «Контур».

### 🧊 3D-просмотр траектории G-кода

Превью теперь можно переключить в интерактивный 3D-режим.

- Переключение 2D / 3D одной кнопкой
- Орбитальная камера: вращение перетаскиванием мыши, зум колесом
- Преднастроенные ракурсы: Сверху, Спереди, Сбоку, Изометрия
- Анимация прохода траектории ползунком прогресса
- Подсветка текущей строки G-кода синхронно с анимацией
- Цветовая индикация: холостой ход, рабочий ход (выполнено / не выполнено), маркеры старта и финиша

### 🌐 HTML-версия приложения

Доступна полностью браузерная версия — без установки Python и зависимостей.

**▶ <https://pavelsirotkin.github.io/PictureToG-Code/Html/>**

- Все вычисления выполняются локально в браузере, изображения никуда не загружаются
- Те же функции: контур, средняя линия, рельеф, шаблоны
- Интерактивный 3D-просмотр траектории на WebGL (Three.js)
- Настройки сохраняются в `localStorage`
- Исходники — в папке `Html/`
