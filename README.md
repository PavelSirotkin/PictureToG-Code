# PictureToG-Code

Браузерный конвертер растровых изображений в G-код для станков с ЧПУ.

**[Открыть конвертер](https://pavelsirotkin.github.io/PictureToG-Code/Html/)**

Обработка изображения и генерация G-кода выполняются в браузере. Для работы с сайтом установка Python не требуется. Настройки сохраняются в локальном хранилище браузера.

## Возможности

- Контурная обработка, в том числе многопроходная и с мостиками.
- Гравировка по средней линии изображения.
- Генерация рельефа по яркости изображения с выбором стратегии и подачи врезания.
- Параметрические шаблоны, масштабирование, бинаризация и сглаживание контуров.
- Просмотр контуров и траектории, 3D-предпросмотр и анимация.
- Скачивание G-кода в текстовом формате ASCII с окончаниями строк CRLF для TurboCNC.

## Использование

1. Откройте конвертер и загрузите изображение либо выберите шаблон.
2. Выберите режим обработки и задайте размеры, параметры фрезы, подачу и глубину.
3. Для контура при необходимости задайте число проходов и параметры мостиков.
4. Сгенерируйте G-код, проверьте траекторию в предпросмотре и сохраните файл.

Мостики выполняются на последнем проходе: инструмент поднимается до поверхности материала и возвращается на глубину обработки. В режиме средней линии мостики и компенсация радиуса не применяются.

Компенсация смещает границу окрашенной области внутрь на радиус фрезы: внешние границы сужаются, внутренние отверстия расширяются. Используется библиотека Clipper (Boost Software License 1.0); координатная сетка — 0,001 мм, допуск аппроксимации скруглений — 0,005 мм. При обнаружении изменения числа контуров генерация останавливается с сообщением; эта проверка не гарантирует обнаружения всех изменений топологии. Перед обработкой проверяйте траекторию и параметры на своём станке.

## Структура репозитория

- `Html/` — интерфейс и браузерный генератор.
- `Html/tests/` — проверки контурного генератора.
- `Samples/` — примеры изображений и G-кода.
- `Screenshot/` — сохранённые снимки предыдущих версий.
- `release_notes.md` — исторические заметки о выпусках, включая прежнее настольное приложение.

Для проверки контурного генератора установленным Node.js выполните:

```bash
node Html/tests/test-contours.js
```

3D-предпросмотр использует Three.js, загружаемый из внешних источников. Лицензия проекта приведена в `LICENSE`, лицензия Clipper — в `Html/js/CLIPPER-LICENSE.txt`.
